Continuous Fourier Transform Explorer

Phase is hidden where |X| is below 0.1% of its peak, since it is undefined there. A time shift t₀ multiplies X by e^(−j2πft₀): magnitude is unchanged, phase gains a straight line, and real and imaginary parts mix.

x(t) ↔ X(f)

X(t) ↔ x(−f)

X(0) = ∫ x(t) dt

Numerical integrals use a midpoint sum over a wide finite window (|t| ≤ 60 s and the equivalent frequency span). At a jump discontinuity (for example the start of the exponential at t₀ = 0) the inverse transform returns the midpoint of the jump, which is why x(0) = A/2 there.

Viva: what is the Fourier transform of x(t) = 1?

Answer: 1 ↔ δ(f) in the Hz form, which is the same as 1 ↔ 2π δ(ω) in the rad/s form.

Derivation using duality, starting from δ(t) ↔ 1

  1. Take x(t) = δ(t). By the sifting property, X(f) = ∫ δ(t) e^(−j2πft) dt = e⁰ = 1. So δ(t) ↔ 1.
  2. Duality says that if x(t) ↔ X(f), then X(t) ↔ x(−f). Here X(f) = 1 for all f, so X(t) is the constant 1.
  3. Therefore 1 ↔ x(−f) = δ(−f) = δ(f), because δ is an even function.
  4. In angular frequency, δ(f) = δ(ω/2π) = 2π δ(ω), so 1 ↔ 2π δ(ω). The extra 2π is the same factor the Duality tab shows in rad/s mode: X(t) ↔ 2π x(−ω).

Consistency checks

  • Area property: X(0) = ∫ 1 dt = ∞, which matches the infinite spike δ(0). Also ∫ δ(f) df = 1 = x(0).
  • Try it: pick Gaussian and raise σ. The pulse flattens toward a constant, the spectrum narrows toward a spike, and the area tab still reports ∫X df = x(0) = A.
  • Reflection is visible with the exponential: its spectrum A/(a + j2πf) used as a time signal transforms to A·e^(af)·u(−f), a mirrored exponential, which is the x(−f) in the duality statement.
